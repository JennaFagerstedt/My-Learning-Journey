# Courses

Notes, exercises and lab write-ups from my courses in the IT Security Specialist program (class ITS26G).
Each course has its own folder with an overview page and one page per exercise or topic.

| Course | What it covers |
|---|---|
| [Operating Systems: Windows and Linux](operating-systems-windows-linux/) | Windows and Linux command-line tools, DNS and `nslookup`, PowerShell (`Get-Command`, `Get-Help`, `Get-Member`), VMware lab troubleshooting |
| [Python: automating log and text analysis](python/) | Strings, file handling, log filtering, JSON, helper functions, exceptions, `pytest`, `uv`, docstrings. Individual assignment RANSOM!: decrypting a ransom note, analysing a badge access log, finding a stolen computer from GPS data |
